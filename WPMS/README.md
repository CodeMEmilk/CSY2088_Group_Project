# Work Progress Management System

Group project.

## Technology

- Node.js
- MySQL
- HTML
- CSS
- JavaScript

## Architecture

The backend is implemented using Node.js native functionality
and internally developed application modules.

Third-party application frameworks and libraries are avoided
where reasonably possible.

## Project Structure

- `backend/` - Server-side application
- `frontend/` - Client-side application
- `database/` - Database schema and seed data
- `docs/` - Project documentation
